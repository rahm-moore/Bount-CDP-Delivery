# Engagements

One folder per active or past client engagement. Each tracks that specific
engagement's real progress against the [methodology](../methodology/), plus any
engagement-specific deliverables that don't belong in the reusable methodology
(e.g. a client's actual schema field list, actual RACI names, actual risk
register).

## Starting a new engagement

1. Copy [`_TEMPLATE/`](_TEMPLATE/) to `<client-name>/`.
2. Fill in `STATUS.md` — client name, platform, current phase.
3. As you produce real deliverables (filled-in templates from `methodology/`),
   keep copies here under the client's folder, not in `methodology/` — the
   methodology folder stays generic and reusable.

## Answering "where am I / what's next" for a specific engagement

Open `<client-name>/STATUS.md`, then follow
[`../methodology/NAVIGATOR.md`](../methodology/NAVIGATOR.md).
