# Handoff Package Checklist

## Architecture & Design

- [ ] Current-state architecture diagram (as-built, not just as-designed)
- [ ] System Context, Data Flow, and Identity Resolution diagrams (as-built)
- [ ] Schema/data model documentation (as-built)
- [ ] Identity resolution design (as-built)
- [ ] Consent & governance design (as-built)
- [ ] Integration architecture (as-built, including every source/destination
      actually in production)

## Operational

- [ ] Environment promotion plan and access list
- [ ] Go-live runbook (as executed, with any deviations noted)
- [ ] Rollback procedure
- [ ] Monitoring/alerting configuration and what each alert means
- [ ] Known issues / open gap list, with severity and status

## Governance & History

- [ ] Full decision log
- [ ] Full risk register with current status per risk
- [ ] RACI matrix (final, as-operated version)
- [ ] Governance/operating model document (see
      [`governance-operating-model.md`](governance-operating-model.md))

## Roadmap

- [ ] Post-launch optimization roadmap (deferred gaps, technical debt, future use
      cases)
